# UNP_VAC_PROJECT_AURA_THERAPEUTICS_USING_MS_EXCEL

Pharmaceutical Distribution Analytics | Excel

Developed in collaboration with **UNP Education**, this project focuses on analysing pharmaceutical distribution data to uncover business insights and support data-driven decision-making.

The project involves data preprocessing, missing value treatment, outlier analysis, dummy variable creation, pivot tables, dashboards, Z-test, T-test, ANOVA, correlation analysis, Simple Linear Regression, and Multiple Linear Regression using Microsoft Excel.

The analysis aims to identify business trends, evaluate key performance indicators, understand relationships between variables, and provide recommendations for improving distribution efficiency, forecasting, and business performance.
